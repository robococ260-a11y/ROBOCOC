02 // IDENTIDAD DEL SISTEMA

Un vehículo. Una plataforma completa.

ROBO-COC significa Control, Operación y Conducción. El proyecto integra estructura mecánica, potencia, sensores, programación, automatización e interfaz web en una sola plataforma capaz de responder a comandos y a su entorno.

03 // MECATRÓNICA APLICADA · INTECAP

La ingeniería detrás de ROBO-COC.

El proyecto es mecatrónico porque cada disciplina aporta una función específica y todas trabajan como un único sistema: percibir, procesar, decidir y ejecutar.

01

MecánicaESTRUCTURA + MOVIMIENTO

Chasis, montaje, ruedas, distribución de masa y transmisión del movimiento mediante cuatro motores de corriente directa.

02

ElectrónicaSENSORES + ACTUADORES

ESP32, drivers L298N, HC-SR04, iluminación, direccionales, bocina, alimentación y cableado forman la capa física de control.

03

ProgramaciónWEB + FIRMWARE

El software interpreta órdenes de la interfaz, procesa información, administra estados y comunica el navegador con el microcontrolador.

04

AutomatizaciónDECISIÓN + RESPUESTA

El PWM regula la potencia y el modo automático puede usar distancias ultrasónicas para responder ante obstáculos.
