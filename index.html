03 // MECATRÓNICA APLICADA

LA INTEGRACIÓN DEL PROYECTO.

ROBO-COC es un sistema mecatrónico porque combina mecánica, electrónica, programación, control y automatización para que el vehículo pueda percibir su entorno, tomar decisiones y ejecutar movimientos.

SISTEMA ROBO-COC MECATRÓNICA
01

MECÁNICA

Estructura del vehículo, montaje, ruedas, distribución de componentes y transmisión del movimiento mediante los cuatro motores DC.

ESTRUCTURA + MOVIMIENTO
02

ELECTRÓNICA

ESP32, drivers L298N, sensores HC-SR04, luces, direccionales, bocina y conexiones eléctricas forman el sistema electrónico.

SENSORES + ACTUADORES
03

PROGRAMACIÓN

El software interpreta comandos de la página web, controla entradas y salidas, procesa lecturas y ejecuta las funciones del vehículo.

ESP32 + INTERFAZ WEB
04

CONTROL Y AUTOMATIZACIÓN

El PWM regula la velocidad y el modo automático utiliza las distancias de los sensores para avanzar, retroceder o girar ante obstáculos.

DECISIÓN + RESPUESTA
ENTRADA SENSORES / USUARIO
PROCESAMIENTO ESP32
SALIDA MOTORES / LUCES / BOCINA
¿POR QUÉ ES MECATRÓNICA?

Porque ninguna parte trabaja de forma aislada: los sensores obtienen información, el ESP32 la procesa mediante software y los actuadores producen una respuesta física. Esa integración entre sistemas mecánicos, electrónicos y de control es la base de ROBO-COC.
