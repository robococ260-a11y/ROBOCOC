🤖 ¿Qué es ROBO-COC?

ROBO-COC es un proyecto de carrito robótico desarrollado para integrar diferentes tecnologías de control y automatización. El ESP32 será el controlador principal, encargado de recibir las órdenes de la interfaz web y controlar los diferentes componentes electrónicos.

🎯 Objetivos

  • Controlar el movimiento del carrito.
  • Incorporar dos sensores de aproximación.
  • Controlar luces y direccionales.
  • Incorporar una bocina.
  • Implementar control de velocidad.
  • Preparar futuras ampliaciones.
HARDWARE

Componentes principales

Elementos que forman parte del sistema ROBO-COC.

🧠

ESP32

Controlador principal del carrito, con comunicación inalámbrica y múltiples GPIO.

⚙️

Motores

Permiten el movimiento del carrito hacia adelante, atrás, izquierda y derecha.

🔌

L298N

Driver de potencia utilizado para controlar los motores desde el ESP32.

📡

Sensores

Dos sensores de aproximación para detectar obstáculos delante y detrás.

💡

Luces

Sistema de iluminación, direccionales y luces de emergencia.

🔊

Bocina

Sistema sonoro controlado desde la interfaz web.
