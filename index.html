¿Qué significa COC?

C

CONTROL

Control electrónico de los motores, sensores y sistemas del vehículo.

O

Gestión y funcionamiento de los diferentes sistemas electrónicos.

01 / PROYECTO

Mecatrónica aplicada a la robótica.

ROBO-COC integra mecánica, electrónica, programación, automatización y comunicación inalámbrica en un vehículo robótico funcional.

01
⚙

Sistema robótico

El carrito utiliza un ESP32 como controlador principal para administrar motores, sensores y diferentes dispositivos electrónicos.

02
⌁

Comunicación

La interfaz web está preparada para comunicarse mediante Wi-Fi con el ESP32 y enviar instrucciones al vehículo.

03
◈

Automatización

El proyecto permite implementar diferentes funciones automáticas utilizando sensores y programación.
